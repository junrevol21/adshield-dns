Router & Network Setup Guide
Your AdShield DNS Server IP:
127.0.0.1
Enter this IP address as the Primary DNS in your Wi-Fi router's DHCP settings.
Quick Router Steps (TP-Link, Asus, Tenda, Huawei, Mikrotik):
  1. Open browser and login to router admin (usually 192.168.1.1 or 192.168.100.1).
  2. Navigate to LAN -> DHCP Server.
  3. Set Primary DNS Server IP to your AdShield IP shown above.
  4. Set Secondary DNS Server IP to 1.1.1.1 (fallback).
  5. Save and reconnect devices to Wi-Fi. All network traffic will now be filtered!
